# TestFlight Upload Handoff

This document captures the current release-candidate state and the exact manual steps needed to complete TestFlight upload.

## Current Candidate Status

- After `Product → Archive`, the `.xcarchive` appears in Xcode **Organizer** (not required to live inside this repo).
- Real iPhone QA evidence is recorded in `RELEASE_QA_CHECKLIST.md` when that checklist is maintained for the build.

## Upload Blockers Found In Terminal

Automated export/upload was attempted and failed due to local account/signing prerequisites:

- `No Accounts with App Store Connect Access`
- `No signing certificate "iOS Distribution" found`
- `No profiles for 'com.navafit.alignment' were found`
- `No Account for Team "XWEML9LWM2"`

## Manual Unblock Steps (Xcode UI)

1. Open Xcode -> `Settings` -> `Accounts`.
2. Add/sign in your Apple ID that has App Store Connect access.
3. Under that team, open `Manage Certificates...` and create an `Apple Distribution` certificate if missing.
4. Open `ios/App/App.xcodeproj`.
5. In `Signing & Capabilities` for target `App`:
   - select team `XWEML9LWM2`,
   - keep automatic signing enabled,
   - confirm the bundle id remains `com.navafit.alignment`,
   - confirm `HealthKit` capability remains enabled.
6. Product -> `Archive` (if needed, rebuild with incremented build number).
7. In Organizer: `Distribute App` -> `App Store Connect` -> `Upload`.
8. Finish upload and wait for processing in App Store Connect -> TestFlight.

## Post-Upload Sanity

After the build appears in TestFlight:

1. Add internal testers.
2. Install from TestFlight on a physical iPhone.
3. Re-run quick smoke tests:
   - Apple/Google/Email auth,
   - consent flow,
   - HealthKit permission + sync,
   - stopwatch save and session restore.
