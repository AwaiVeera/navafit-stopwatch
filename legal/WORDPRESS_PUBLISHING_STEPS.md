# WordPress Publishing Steps For NavaFit Legal Pages

Use this guide to publish the prepared legal drafts from this repository onto the live WordPress site at `https://navafit.sg`.

## Source Files To Use
- `legal/privacy-policy.md`
- `legal/terms-of-service.md`

## Target URLs
- `https://navafit.sg/privacy-policy/`
- `https://navafit.sg/terms-of-service/`

## Current Published Status
- The privacy page is live at `https://navafit.sg/privacy-policy/`
- The terms page is live at `https://navafit.sg/terms-of-service/`
- Use this file again when those pages need to be updated or republished

## Before You Start
Make sure you can log into the WordPress admin dashboard for the live site.

## Publish The Privacy Policy Page

1. Open your browser.
2. Go to the WordPress admin login for your site.
3. Sign in.
4. In the WordPress left sidebar, click `Pages`.
5. Click `Add New Page`.
6. In the title box at the top, type:
   `Privacy Policy`
7. Open the local file `legal/privacy-policy.md`.
8. Copy all of the text from that file.
9. Go back to WordPress.
10. Click inside the main page content area.
11. Paste the full text.
12. Check that the headings and paragraphs appear correctly.
13. Open the page settings or permalink settings on the right side.
14. Set the page slug to:
    `privacy-policy`
15. Click `Publish`.
16. Click `Publish` again if WordPress asks for confirmation.

## Publish The Terms Page

1. In the WordPress left sidebar, click `Pages`.
2. Click `Add New Page`.
3. In the title box at the top, type:
   `Terms of Service`
4. Open the local file `legal/terms-of-service.md`.
5. Copy all of the text from that file.
6. Go back to WordPress.
7. Click inside the main page content area.
8. Paste the full text.
9. Check that the headings and paragraphs appear correctly.
10. Open the page settings or permalink settings on the right side.
11. Set the page slug to:
    `terms-of-service`
12. Click `Publish`.
13. Click `Publish` again if WordPress asks for confirmation.

## Verify The Public URLs

After both pages are published:

1. Open a new browser tab.
2. Visit:
   `https://navafit.sg/privacy-policy/`
3. Confirm the page loads publicly.
4. Open another tab and visit:
   `https://navafit.sg/terms-of-service/`
5. Confirm the page loads publicly.

## Final Check

If both pages load publicly without requiring a WordPress login, the legal URL task can be treated as complete.

At that point, those URLs can be used in:
- Google Auth branding or consent configuration
- future app legal links
- support and compliance references
